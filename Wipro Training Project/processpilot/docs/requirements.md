# 📋 ProcessPilot Technical Requirements

## Requirements Matrix
- **C++ Standard**: C++17
- **Operating System**: Linux (Kernel 4.x / 5.x / 6.x)
- **Compiler**: GCC 7+ or Clang 6+
- **Process Control**: POSIX `fork()`, `execvp()`, `waitpid()`, `kill()`
- **IPC Protocol**: UNIX Domain Sockets (`SOCK_STREAM`)
