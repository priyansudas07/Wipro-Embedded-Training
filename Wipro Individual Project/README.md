# Wipro Individual Project

This directory contains the individual capstone projects developed for the Wipro Embedded Systems Training.

## Projects List

### 1. VDevPulse (`vdevpulse/`)
- **Title**: VDevPulse: Linux Virtual Device Interface & System Telemetry Monitor
- **Language**: Modern C++17
- **Description**: High-performance system daemon bridging POSIX virtual character device I/O (`/tmp/vdevpulse`) with kernel `/proc` telemetry monitoring (`/proc/stat`, `/proc/meminfo`, `/proc/loadavg`, `/proc/uptime`). Features an automated threshold alert engine, interactive text query protocol, structured JSON export streaming, in-memory historical telemetry buffer, extended IOCTL suite, thread-safe logging, automated CMake unit tests (100% CTest pass), and full 6-stage SDLC engineering documentation.
- **Link**: [vdevpulse/](./vdevpulse)
