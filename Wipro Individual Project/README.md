# Wipro Individual Project

This directory contains the individual capstone projects developed for the Wipro Embedded Systems Training.

## Projects List

### 1. VDevPulse (`vdevpulse/`)
- **Title**: VDevPulse: Linux Virtual Device Interface & System Telemetry Monitor
- **Language**: Modern C++17
- **Description**: High-performance system daemon bridging POSIX virtual character device I/O (`/dev/vdevpulse`) with kernel `/proc` telemetry monitoring (`/proc/stat`, `/proc/meminfo`). Includes dynamic JSON configuration, thread-safe logging, automated CMake unit tests, and full 6-stage SDLC documentation.
- **Link**: [vdevpulse/](./vdevpulse)
