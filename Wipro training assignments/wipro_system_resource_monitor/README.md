# Linux System Resource Monitor (C++)

C++ program using `<filesystem>` and `<fstream>` to monitor processes, display PID status details, and write a report to `process_report.txt`.

## Files
- `main.cpp` - C++ source file
- `Makefile` - Build file (`g++ -std=c++17`)

## Compilation and Execution
```bash
make
./resource_monitor
```
