# Wipro Training Assignments

This folder contains all completed lab assignments for the Wipro COE Embedded Systems training program.

## Assignments

- `wipro_system_info_tool/` - Assignment 1: Linux System Information Tool (C)
- `wipro_process_monitor/` - Assignment 2: Linux Process Monitor (C)
- `wipro_system_resource_monitor/` - Assignment 3: Linux System Resource Monitor (C++)

## Instructions

Navigate to any assignment directory and run `make` to compile.
