# Wipro Training Assignments

This folder contains all completed lab assignments for the Wipro COE Embedded Systems training program, all written in C++.

## Assignments List

- [`wipro_system_info_tool/`](./wipro_system_info_tool) - Assignment 1: Linux System Information Tool (C++)
- [`wipro_process_monitor/`](./wipro_process_monitor) - Assignment 2: Linux Process Monitor (C++)
- [`wipro_system_resource_monitor/`](./wipro_system_resource_monitor) - Assignment 3: Linux System Resource Monitor (C++)

## Build & Execution Instructions

Navigate to any assignment directory and run:

```bash
make
```

To clean up object files and binary executables:

```bash
make clean
```
